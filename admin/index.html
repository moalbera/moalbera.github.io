لوحة التحكم

أهلاً محمد 👋

باش تدخل للوحة، تحتاج مفتاح دخول من GitHub. تديره مرة وحدة بس، واللوحة تتذكره على الجهاز هذا.

  1. افتح الرابط هذا: إنشاء مفتاح جديد
  2. في خانة Token name اكتب: لوحة التحكم
  3. في Expiration اختار أطول مدة متاحة.
  4. في Repository access اختار Only select repositories وبعدين اختار moalbera.github.io
  5. في Permissions اضغط Add permissions واختار Contents، وبعدين بدّلها لـ Read and write
  6. انزل لتحت واضغط Generate token، وانسخ المفتاح (يبدأ بـ github_pat_)
  7. الصقه هني تحت واضغط دخول.
